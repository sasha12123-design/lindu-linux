# lindu-wm — собственный оконный менеджер

Тайловый оконный менеджер для X11, написанный с нуля на C/Xlib
(~1000 строк без зависимостей, кроме libX11 + libXinerama).

## Идеи дизайна

- **Один файл + config.h** — как отлаживаемая, но независимая реализация.
- **Мониторы** — через Xinerama: у каждого экрана свой тег, раскладка,
  панель и стек. Окна привязываются к монитору (`Client->mon`).
- **Регулирование через теги**: 9 рабочих столов, окно может быть на нескольких.
- **Три раскладки**: TILE (мастер + стек), MONOCLE, FLOAT — на каждый монитор.
- **Панель встроена** — по одной на монитор, показывает номер экрана `M1`,
  теги, раскладку и часы.
- **EWMH минимум**: _NET_SUPPORTED, _NET_ACTIVE_WINDOW, _NET_WM_STATE.

## Мониторы

- Определяются автоматически через `XineramaQueryScreens`; если вызов
  не сработал — используется один монитор на весь экран.
- Панели рисуются на верхней кромке каждого экрана, тайловый мастедер
  считается в пределах рабочей области экрана.
- `Mod+Left/Right` — переключить активный монитор,
  `Mod+Shift+Left/Right` — отправить окно на соседний.
- Фокусу следует за мышью и автоматически «переключает» монитор.

## Сборка и установка

```bash
sudo pacman -S --needed base-devel libx11 libxinerama
cd wm/
make            # gcc -O2 -std=c99 lindu-wm.c -lX11 -lXinerama
sudo make install   # -> /usr/local/bin/lindu-wm
```

## Структура

| Файл         | Назначение                                |
|--------------|-------------------------------------------|
| `lindu-wm.c` | весь код менеджера                         |
| `config.h`   | ключи, цвета, размеры, раскладки ‑ настраивается |
| `Makefile`   | сборка/установка (`PREFIX`, `DESTDIR`)     |

## config.h — главная точка настройки

```c
#define BARH 26        // высота панели
#define ACCENT "#79d7f0"
#define MASTERFACTOR 55  // процент ширины мастера
#define MODKEY Mod4Mask  // Super
static Key keys[] = { ... }; // таблица клавиш
```

## Логика работы

```
события X (MapRequest, ConfigureRequest, KeyPress, ...)
   └─ список клиентов (все окна)
        └─ фильтр по тегу (текущий рабочий стол)
             └─ раскладка: tile() / monocle() / floating()
                  └─ resize() -> XConfigureWindow
```

Фокус следует за мышью (sloppy) и поднимает окно вверх (EWMH).
