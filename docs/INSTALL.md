# Установка lindu linux на диск

Live-система включает два установщика:

- **`lindu-install-gtk`** — графический мастер (Python + Gtk3), запускается
  с рабочего стола (`Mod+d` → «Установка lindu linux»);
- **`lindu-install`** — текстовый CLI-мастер, работает даже без X.

## Графически (рекомендуется)

На рабочем столе нажмите `Mod+d` и запустите **«Установка lindu linux»**
(запросит пароль `lindu` для прав root). Мастер предложит шаги:

1. **Диск** — выберите из списка; подтвердите, что данные будут удалены.
2. **Параметры** — файловая система (`ext4`/`btrfs`), swap, имя хоста, часовой пояс.
3. **Пароли** — по умолчанию `lindu / lindu` и `root / lindu` либо свои.
4. **Установка** — прогресс-бар, журнал, pacstrap, GRUB.
5. **Готово** — кнопка «Перезагрузить».

Мастер последовательно спросит:

1. **Диск** — выберите из списка (например `sda`, `nvme0n1`). Весь диск
   будет пересоздан!
2. **Файловая система** — `ext4` (по умолчанию) или `btrfs`.
3. **Swap** — создать ли отдельный раздел подкачки.
4. **Имя хоста** и **часовой пояс** (например `Europe/Moscow`).
5. Пароли — согласиться на значения по умолчанию (`lindu / lindu`, `root / lindu`)
   или задать свои пошагово.

Что происходит внутри (для справки):

- разметка **GPT**: 1 MiB `bios_grub` + ESP (FAT32) + корень (+ swap);
- форматирование разделов;
- `pacstrap` — установка базы и всего рабочего стола lindu;
- `genfstab` — файл `/etc/fstab`;
- настройка в chroot: `locale`, хост, пользователь `lindu` (wheel),
  сервисы `NetworkManager`, `sshd`, пароли, `sudoers`;
- загрузчик **GRUB** (UEFI и BIOS) с `grub-mkconfig`;
- копирование `lindu-wm`, обоев и конфигов пользователя, **autologin на tty1**.

По окончании — предложение перезагрузиться. Готово: вы в своей системе.

## Вручную

Онлайн-гайд Arch (загрузка ISO, разметка, `pacstrap`), затем настроить как в
[`lindu-install`](../installer/lindu-install). Главное — поставить пакеты
`xorg-server libx11 libxinerama` и скопировать `lindu-wm`.
